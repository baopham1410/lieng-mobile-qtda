# Thẩm định & quầy tư vấn

## Thẩm định AutoGrade
Menu **Dịch vụ → Thẩm định** → `/appraisal`.
1. Tạo phiếu thu cũ / định giá.
2. Upload ảnh máy (góc + màn / pin).
3. Checklist nội vi.
4. Chạy AutoGrade (UI demo → gắn YOLO/OCR sau).
5. Lưu FinalPrice / trạng thái báo giá.

## Quầy tư vấn (hotline)
Menu **Dịch vụ → Tư vấn** → `/consult`.
- Khách ngoài bấm **Gọi ngay** (`tel:0383435600`).
- NV tiếp nhận tại quầy: ghi SĐT, tên, nhu cầu, ghi âm cuộc gọi.
- Kết thúc: Xong / Nhỡ máy / Hẹn gọi lại.
